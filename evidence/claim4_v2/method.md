# Method

Run the paper's five-state composite family beyond its reported 100 epochs: 128 independent paths for each of three alternatives and five log thresholds through 5,120. Separately sweep 2,000 null paths across 21 parameters and every initial state. An exact normalized-Dirichlet mixture certificate proves infinite-horizon alpha control, while deterministic stationary flows cover dense, sticky, and cyclic families in 3/5/10/25/50 states through log threshold 1e8.
